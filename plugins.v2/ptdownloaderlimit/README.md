# QB&TR上传限速

按下载器、PT 站点标签和时间段设置 qBittorrent、Transmission 种子的上传限速。

- 支持动态新增、删除、折叠和排序任意数量规则。
- 规则按列表顺序逐条执行；同一下载器与站点命中多条规则时，靠后的规则最终生效，靠后规则不在限速时间段时会解除前面规则的限速。
- 时间段留空时全天有效，支持跨午夜时间段，例如 `09:00-02:00`。
- 上传速度为 `0` 时解除限速；“不限速标签”中的种子不会由插件管理。

前端构建：

```bash
cd plugins.v2/ptdownloaderlimit && npm install && npm run build
```
